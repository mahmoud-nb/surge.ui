# Composants d'affichage

Les composants d'affichage servent à présenter du contenu visuel : titres, images, badges, modales, indicateurs de progression, etc.

## Typographie et structure

| Composant | Description |
|-----------|-------------|
| [Heading](/components/heading) | Titres sémantiques (h1-h6) avec tailles et poids configurables |
| [Panel](/components/panel) | Conteneur de surface avec bordure et ombre optionnelle |
| [Divider](/components/divider) | Trait de séparation, avec texte optionnel |
| [Kbd](/components/kbd) | Touche ou raccourci clavier |
| [VisuallyHidden](/components/visuallyhidden) | Contenu réservé aux lecteurs d'écran |
| [Icon](/components/icon) | Icônes SVG avec taille et couleur personnalisables |

## Médias et identité

| Composant | Description |
|-----------|-------------|
| [Image](/components/image) | Image avec ratios, sources multiples et lazy loading |
| [Avatar](/components/avatar) | Avatar avec initiales, statut et badges |
| [AvatarGroup](/components/avatargroup) | Groupe d'avatars avec gestion du surplus |
| [Tag](/components/tag) | Étiquette retirable (filtre, mot-clé) |
| [Badge](/components/badge) | Badge avec variantes, icônes et couleurs personnalisables |

## Overlays et conteneurs

| Composant | Description |
|-----------|-------------|
| [ConfirmDialog](/components/confirmdialog) | Confirmation par promesse avec useConfirm() |
| [Dialog](/components/dialog) | Modale/tiroir polyvalent (center, left, right, top, bottom, full) |
| [Popover](/components/popover) | Bulle contextuelle avec placement intelligent |
| [Tooltip](/components/tooltip) | Infobulle au survol et au focus clavier |
| [Alert](/components/alert) | Alerte informative avec types success, warning, error, info |
| [Toast](/components/toast) | Notifications éphémères avec useToast() et SuToaster |
| [Tabs](/components/tabs) | Onglets avec variantes underline, contained et pills |
| [Accordion](/components/accordion) | Panneaux dépliables avec ouverture simple ou multiple |
| [Collapse](/components/collapse) | Zone dépliable individuelle |
