# Composants de formulaire

Les composants de formulaire permettent la saisie et la validation de données : champs texte, sélecteurs, interrupteurs, upload de fichiers, etc.

## Champs de saisie

| Composant | Description |
|-----------|-------------|
| [Input](/components/input) | Champ texte avec préfixe, suffixe et icônes |
| [Textarea](/components/textarea) | Zone de texte avec compteur et auto-resize |
| [Password](/components/password) | Champ mot de passe avec validation et barre de progression |

## Sélection

| Composant | Description |
|-----------|-------------|
| [SelectBox](/components/selectbox) | Liste déroulante avec sélection simple ou multiple |
| [RadioGroup](/components/radio-group) | Groupe radio pour sélection unique avec modes d'affichage |
| [CheckboxGroup](/components/checkbox-group) | Groupe checkbox pour sélection multiple avec modes d'affichage |
| [Switch](/components/switch) | Interrupteur on/off avec labels optionnels |

## Valeurs et fichiers

| Composant | Description |
|-----------|-------------|
| [Slider](/components/slider) | Curseur pour valeurs numériques avec marqueurs |
| [FileUpload](/components/fileupload) | Upload de fichiers avec drag & drop et prévisualisation |

## Structure et validation

| Composant | Description |
|-----------|-------------|
| [FormField](/components/formfield) | Wrapper de champ avec label, message et état de validation |
| [FormFieldGroup](/components/formfieldgroup) | Groupe de champs avec espacement et direction configurables |
