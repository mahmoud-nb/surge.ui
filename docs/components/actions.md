# Composants d'actions

Les composants d'actions permettent à l'utilisateur d'interagir : boutons, liens, toggles, menus déroulants, etc.

## Boutons

| Composant | Description |
|-----------|-------------|
| [Button](/components/button) | Bouton avec variantes primary, secondary, outline, ghost |
| [ButtonGroup](/components/buttongroup) | Groupe de boutons avec espacement contrôlé et mode connecté |
| [FloatButton](/components/floatbutton) | Bouton flottant positionné dans les coins de l'écran |

## Liens

| Composant | Description |
|-----------|-------------|
| [Link](/components/link) | Lien avec support des icônes et variantes |
| [LinkGroup](/components/linkgroup) | Groupe de liens avec séparateurs et espacement |

## Toggles

| Composant | Description |
|-----------|-------------|
| [Toggle](/components/toggle) | Bouton basculable on/off avec label ou icône |
| [ToggleGroup](/components/togglegroup) | Groupe de toggles avec sélection exclusive ou multiple |

## Menus

| Composant | Description |
|-----------|-------------|
| [Dropdown](/components/dropdown) | Menu déroulant avec options, icônes et liens |
