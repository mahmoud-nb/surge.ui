# Action Components

Action components enable user interaction: buttons, links, toggles, dropdown menus, and more.

## Buttons

| Component | Description |
|-----------|-------------|
| [Button](/en/components/button) | Button with primary, secondary, outline, ghost variants |
| [ButtonGroup](/en/components/buttongroup) | Button group with controlled spacing and connected mode |
| [FloatButton](/en/components/floatbutton) | Floating button positioned at screen corners |

## Links

| Component | Description |
|-----------|-------------|
| [Link](/en/components/link) | Link with icon support and variants |
| [LinkGroup](/en/components/linkgroup) | Link group with separators and spacing |

## Toggles

| Component | Description |
|-----------|-------------|
| [Toggle](/en/components/toggle) | Toggleable on/off button with label or icon |
| [ToggleGroup](/en/components/togglegroup) | Toggle group with exclusive or multi-selection |

## Menus

| Component | Description |
|-----------|-------------|
| [Dropdown](/en/components/dropdown) | Dropdown menu with options, icons and links |
