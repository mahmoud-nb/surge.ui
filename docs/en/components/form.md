# Form Components

Form components handle data input and validation: text fields, selectors, switches, file uploads, and more.

## Input fields

| Component | Description |
|-----------|-------------|
| [Input](/en/components/input) | Text field with prefix, suffix and icons |
| [Textarea](/en/components/textarea) | Text area with counter and auto-resize |
| [Password](/en/components/password) | Password field with validation and progress bar |

## Selection

| Component | Description |
|-----------|-------------|
| [SelectBox](/en/components/selectbox) | Dropdown list with single or multiple selection |
| [RadioGroup](/en/components/radio-group) | Radio group for single selection with display modes |
| [CheckboxGroup](/en/components/checkbox-group) | Checkbox group for multiple selection with display modes |
| [Switch](/en/components/switch) | On/off switch with optional labels |

## Values and files

| Component | Description |
|-----------|-------------|
| [Slider](/en/components/slider) | Slider for numeric values with markers |
| [FileUpload](/en/components/fileupload) | File upload with drag & drop and preview |

## Structure and validation

| Component | Description |
|-----------|-------------|
| [FormField](/en/components/formfield) | Field wrapper with label, message and validation state |
| [FormFieldGroup](/en/components/formfieldgroup) | Field group with configurable spacing and direction |
