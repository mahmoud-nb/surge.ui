# Display Components

Display components present visual content: headings, images, badges, modals, progress indicators, and more.

## Typography and structure

| Component | Description |
|-----------|-------------|
| [Heading](/en/components/heading) | Semantic headings (h1-h6) with configurable sizes and weights |
| [Panel](/en/components/panel) | Surface container with border and optional shadow |
| [Icon](/en/components/icon) | SVG icons with customizable size and color |

## Media and identity

| Component | Description |
|-----------|-------------|
| [Image](/en/components/image) | Image with ratios, multiple sources and lazy loading |
| [Avatar](/en/components/avatar) | Avatar with initials, status and badges |
| [AvatarGroup](/en/components/avatargroup) | Avatar group with overflow management |
| [Badge](/en/components/badge) | Badge with variants, icons and customizable colors |

## Overlays and containers

| Component | Description |
|-----------|-------------|
| [Dialog](/en/components/dialog) | Versatile modal/drawer (center, left, right, top, bottom, full) |
| [Popover](/en/components/popover) | Contextual popover with smart placement |
| [Alert](/en/components/alert) | Informational alert with success, warning, error, info types |
| [Tabs](/en/components/tabs) | Tabs with underline, contained and pills variants |
| [Accordion](/en/components/accordion) | Collapsible panels with single or multiple open mode |
| [Collapse](/en/components/collapse) | Individual collapsible section |

## Indicators

| Component | Description |
|-----------|-------------|
| [Progress](/en/components/progress) | Progress bar with states and indeterminate mode |
| [Spinner](/en/components/spinner) | Loading indicator with 5 animation styles |
