## Barre d’outils

Les réglages en haut de l’aperçu s’appliquent à toutes les stories :

- **Theme** : default, ocean, forest, sunset
- **Theme Mode** : clair, sombre
- **Direction** : LTR, RTL
- **Langue** : français, anglais, arabe

Le panneau **Accessibility** (addon a11y) analyse chaque story avec axe.

## Organisation

- **Global** : vitrines qui assemblent les composants.
- **Atoms** : composants de base (Button, Input, Badge…).
- **Molecules** : compositions (champs avec libellé, menus, sélecteurs de date…).
- **Organisms** : ensembles complexes (Dialog, Tabs, DataTable…).
- **Templates** : gabarits de page.
